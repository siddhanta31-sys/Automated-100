# Trend2Sketch — Design Director R&D Mode

This build changes Deep mode from “larger pool” into a jewellery product-development workflow.

## What Deep mode now does
1. Runs three independent live-web research lenses: regional/design grammar, commercial/catalogue signals, and manufacturing/CAD feasibility.
2. Synthesizes those findings into an R&D map with families, sub-families, construction rules, stone architecture, lightweighting and white-space opportunities.
3. Generates CAD-actionable product briefs rather than vague image prompts.
4. Scores concepts across commercial appeal, originality, South Indian authenticity, stone composition, proportion, manufacturability, weight efficiency, wearability, trend relevance and novelty.
5. Renders only shortlisted concepts and visually gates them.
6. Captures owner feedback: Excellent / Usable / Reject + rejection reason. Future Deep research receives recent feedback.

## Recommended first test
Deep mode, 10 designs, acceptance threshold 75. Review all 10 and mark each Excellent / Usable / Reject. After feedback is collected, run another Deep cycle and compare.

Public research is for trend/design signals only. The system is explicitly instructed not to reproduce branded SKUs.
